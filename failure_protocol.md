Failure is assumed to be inevitable.

### When the Agent Is Wrong
If the agent’s decision results in negative impact, the priority is quiet containment.
No justification is issued unless required.
No secondary actions are triggered automatically.

### Who Is Notified
No proactive notifications are sent unless harm crosses the irreversible threshold.
If escalation is required, only one responsible human owner is notified.
No broad alerts. No discussion loops.

### When Nothing Is Done
If correcting the mistake would increase visibility or compound damage, the agent does nothing.
Silence is maintained until a safer corrective window appears.

### How Learning Occurs Without Noise
The agent records the failure internally as a judgment artifact.
No real-time tuning.
No reactive behavior change.
Learning is applied only after patterns repeat across time, not single events.
